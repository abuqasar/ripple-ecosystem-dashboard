# Ripple ecosystem research

Interactive research map covering 177 entries across 17 categories, with integration details, status, four usage KPI fields and links to public sources. Research snapshot: 17 September 2026.

Live website: https://abuqasar.github.io/ripple-ecosystem-dashboard/

## Coverage and evidence

The expanded pass adds 89 entries from XRPL's project directory, selected XRPL Grants recipients, XRPL EVM documentation, Ripple customer announcements, Tenity cohort 6, Berkeley UDAX and Commons hackathons. Programme and prototype entries are explicitly marked as discovery leads, not confirmed production integrations. Adjacent networks and infrastructure are labelled separately.

The grant directory contains 199 recipients; this map includes only a selected subset. Older cohorts, the full EVM directory, NFT/gaming projects, Xahau, regional issuers and non-public integrations remain coverage gaps. Inclusion is not endorsement or an audit. The on-page coverage section links the source directories for continued research.

Usage values are dated, manually curated snapshots. Most integrations lack verified values in this map; that does not establish zero activity or lack of public disclosure. Preserve chain, period, units and metric sources when adding figures.

Click an organisation to inspect its relationship to Ripple, XRPL, RLUSD or adjacent networks. Entries sometimes group multiple companies; the count is not a count of unique companies. This is a research map, not an exhaustive or independently audited integration registry.

## Contribute research

Open a GitHub issue for a correction or addition. Include the organisation, category, network, relationship, integration status, a primary-source URL and the date checked. Do not post confidential client or proposal materials in this public repository.

To update the map, edit `map-source.html`. `S` holds source links; `groups` holds entries and descriptions. Preserve the distinction between available products, announced integrations, directory listings and legacy products. A commercial Ripple customer is not automatically an XRPL application.

Run `python build.py` and commit both the source and generated `index.html`. Preview locally with `python -m http.server 8000`, then open http://localhost:8000.

## Hosting

GitHub Pages can serve directly from the main branch, root folder. The website is static and has no backend, accounts or shared notes database. Research contributions use GitHub issues and pull requests. No confidential presentation content is included.
